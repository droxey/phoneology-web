Privacy

Development version. This page describes Phoneology’s current development build. It will be reviewed before the app is released.

Muse & Machine LLC develops Phoneology. This policy describes the app’s current development build and this website.

Readings and information you enter

Phoneology calculates phone-number readings on your device and does not read your contacts. You may also enter a birthdate for a separate Life Path calculation. That birthdate is stored in local app preferences and can be cleared.

Private mode is on by default and prevents new History saves. Turning it on does not remove readings already saved. Saved readings are stored locally using Apple’s Core Data framework.

Optional iCloud sync

Sync is off by default and requires you to turn it on. A change takes effect on the next app launch. When enabled, the app uses Apple’s iCloud services for supported saved data, including a saved phone number and timestamp. Cross-device behavior is still being verified during development.

Turning sync off retains existing local and remote copies; it does not erase data on other devices. Phoneology has no developer-operated backend. Local deletion does not guarantee complete cloud erasure or recovery.

Diagnostics and this website

The app uses Apple’s OSLog and MetricKit for first-party diagnostics. Diagnostic behavior, any Apple transmission, retention, and release privacy disclosures are being reviewed before launch.

This website is hosted on GitHub Pages. Its source is static and contains no analytics scripts or external automatic resources. GitHub processes network request information to deliver the site and logs visitors’ IP addresses for security.

We have not verified a specific retention period for GitHub’s request data. App diagnostic handling and hosting disclosures will be reviewed before the app is released.

Removing your information

You can delete saved readings, clear your birthdate, or use Settings → Delete all data → Delete to clear accessible local saved readings, birthdate and preferences, and drafts and previews. The operation can be blocked during an active sync operation, when a store cannot be accessed, or when permission is denied.

With sync enabled, deletions may propagate to iCloud or remote records may be imported later. A session connected to sync does not itself mean a sync operation is running. Local deletion does not remove exports, backups, or App Store purchases, and does not guarantee removal of every remote copy.

See Delete data for the current controls and their limits.
